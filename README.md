# Vehiclery

A Minecraft mod adding customizable vehicles, for **NeoForge 26.2 / Minecraft 26.2**.

Vehiclery is a port/continuation of [Automobility](https://github.com/FoundationGames/Automobility) (FoundationGames, MIT).
Original code has been reworked for a single-module NeoForge project targeting Minecraft 26.2.

## Features

- Assemble your own vehicles from parts: frames, engines, wheels and attachments.
- Build roads, racetracks and obstacle courses with slopes, dash panels and off-road tiles.
- Data-driven vehicle parts: add your own custom vehicle types with data packs and resource packs.
- Craft vehicle parts in the Auto Mechanic Table, assemble them on the Automobile Assembler.

## Driving

- W — Accelerate
- S — Brake/Reverse/Burnout
- A/D — Steer left/right
- Space — Drift/Deploy

## Getting Started

- **Recipes:** viewable with EMI or JEI. Automobile part recipes are shown in the Auto Mechanic Table GUI.
- **Automobile Parts:** craft an Auto Mechanic Table, then use it to craft frames, engines, and wheels (optionally attachments).
- **Building:** craft an Automobile Assembler and a Crowbar. Place parts until the vehicle is complete; use the Crowbar to disassemble.
