<h2>v0.0.0-beta.1 - First public build</h2>

<p>First public release of <strong>Vehiclery</strong>, a port/continuation of <a href="https://github.com/FoundationGames/Automobility"><strong>Automobility</strong></a> (FoundationGames, MIT) for <strong>Minecraft 26.2 / NeoForge 26.2.0.37-beta</strong>.</p>

<p>This build is the result of porting the mod through NeoForge 26.2's client rendering API overhaul (block/entity model baking, GUI, item and vehicle renderers, entity data serialization). It compiles and runs, but a handful of visual/UX features are temporarily incomplete while their replacement APIs get implemented properly. See below.</p>

<h3>Features</h3>
<ul>
<li>Assemble custom vehicles from frames, engines, wheels and attachments using the Auto Mechanic Table and Automobile Assembler.</li>
<li>Drive with full controls: accelerate, brake, steer, drift, burnout.</li>
<li>Build roads, ramps and off-road terrain with slope blocks, dash panels and off-road tiles.</li>
<li>Data-driven vehicle parts via data packs and resource packs.</li>
<li>Autopilot signs to guide unmanned vehicles.</li>
</ul>

<h3>Known limitations in this beta</h3>
<ul>
<li>Automobile and component items (frame/wheel/engine/attachments) currently show a flat 2D icon instead of their custom 3D render in hand/inventory.</li>
<li>The banner pattern overlay on the rear attachment flag pole doesn't render yet (the pole itself does).</li>
<li>Passengers riding a vehicle don't visually tilt with the vehicle's motion.</li>
<li>The Auto Mechanic Table's recipe list only loads on singleplayer/server side; on a dedicated server the client-side recipe browser may appear empty until a proper sync packet is implemented.</li>
<li>The automobile speedometer HUD doesn't currently respect the F1 "hide GUI" toggle.</li>
</ul>

<blockquote>This is an early beta of the 26.2 port. Please report issues on the project page — feedback on the above limitations and anything else you run into is very welcome.</blockquote>

<h3>Requirements</h3>
<ul>
<li>Minecraft 26.2</li>
<li>NeoForge 26.2.0.37-beta+</li>
<li>Install on <strong>both client and server</strong></li>
</ul>
